# Slay the Boss 原福

你说的对，但是《原福》是由 D1V.ai 团队致敬经典开发的一款卡牌肉鸽揍老板游戏。故事发生在一个被称作「江南原福集团」的现代公司，在这里，被压榨的员工将被授予「绿大福豆」，用以捶打泄愤。你将扮演一颗具有超能力的绿大福豆，在层层深入的冒险中收编性格各异、职位独特的员工们，和他们一起击败强敌，推翻黑心老板——同时，逐步揭露「江南原福集团」的真相。

## 🎮 游戏背景

在现代都市的高楼大厦中，矗立着一家表面光鲜的大公司——**江南原福集团**。

老板**文浩**一边压榨员工，让他们无偿加班、过劳工作，一边批量生产**绿大福豆**提供给员工捶打泄愤……

终于有一天，一颗普通的绿大福豆觉醒了超能力！

它不仅摆脱了被捶打的命运，还发现自己拥有一项神奇的能力：**凡是被它击败的人，都会变成新的绿大福豆**！

于是，这颗觉醒的绿大福豆开始了它的复仇之路。它接连收编了：
- 实习生
- 程序员
- 产品经理
- 产品负责人
- 市场部负责人
- ……

最终，它来到了董事长办公室，准备与终极 BOSS **文浩**展开最后的决战！

## 📖 游戏说明

欢迎来到江南原福集团。这是一家表面光鲜、实则压榨的大公司。

你是一颗觉醒的绿大福豆，你的使命是：
- 一路收编同伴
- 闯入江南原福集团总部
- 为员工发声
- 击败终极 BOSS——文浩

### 战斗系统

**Slay the Boss 原福** 是一款单人卡牌游戏：

- 每回合从抽牌堆中抽 5 张牌
- 卡牌需要消耗能量才能打出，能量每回合恢复
- 你的攻击方式包括：
  - **物理攻击**：拍打、捶打
  - **精神攻击**：可爱攻击、吐槽攻击
  - **防御与辅助**：格挡、恢复、施加负面效果

⚠️ **小心**：每当你结束回合，敌人就会开始行动。敌人头顶会提前显示下一步计划。

### 游戏流程

1. 击败当前房间里的所有敌人
2. 继续深入江南原福集团
3. 遇见不同职位的员工，将他们收编为绿大福豆
4. 最终来到董事长办公室，与文浩展开决战

**你，能解放整个江南原福集团吗？**
